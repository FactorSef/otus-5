# ABS и ASA

Инженерные стирольные пластики. Термостойкие, хорошо шлифуются, ABS
сглаживается парами ацетона. Высокая усадка — **нужен закрытый корпус**.

## Сравнение

| Параметр | ABS | ASA |
|---|---|---|
| Температура стеклования | ~100–105 °C | ~100 °C |
| Усадка | высокая | средняя–высокая (чуть меньше ABS) |
| УФ-стойкость | **плохая** (желтеет, становится хрупким) | **отличная** |
| Запах / испарения | сильные (стирол) | сильные, чуть мягче |
| Ацетоновое сглаживание | да | да (хуже) |
| Применение | корпуса, детали интерьера, детали для нагрева | всё для улицы: авто, сад, крепёж |

## Базовые настройки

| Параметр | ABS | ASA |
|---|---|---|
| Сопло | 240–270 °C | 245–270 °C |
| Стол | 95–110 °C | 95–110 °C |
| Обдув | 0–30 % | 0–30 % |
| Камера | 40–60 °C желательно | 40–60 °C желательно |
| Brim | 3–10 мм на больших деталях | то же |

## Настройки по принтерам

| | Kobra X ⚠️ | P1S ✅ | K2 ✅ |
|---|---|---|---|
| Сопло | 245–260 °C | 260–280 °C | 250–270 °C |
| Стол | 100 °C (макс.) | 90–100 °C (110 при 220 В) | 100–110 °C |
| Корпус | **нет** — колпак/короб сильно помогает | закрыт, прогрев 10–15 мин | закрыт, прогрев 10–15 мин |
| Обдув | 0–15 % | 10–30 % | 0–20 % |
| Размер деталей | до ~100 мм | весь стол | весь стол |

### Kobra X — как выжать максимум без корпуса
- Комната без сквозняков, принтер в «коробке» (самодельный enclosure из
  картона, ИКЕА LACK + плексиглас или готовый тент).
- Brim 8–10 мм, Mouse ears на острых углах.
- Скругления на углах модели уменьшают коробление.
- Обдув выключен на первых 5 слоях.

## Безопасность

- ABS и ASA выделяют стирол и ультрадисперсные частицы.
- Печатайте в проветриваемом помещении, не в спальне.
- Угольный фильтр P1S / K2 снижает запах, но **не заменяет вентиляции**.

## Типичные проблемы

| Дефект | Причина | Решение |
|---|---|---|
| Углы отходят от стола | усадка, холодный воздух | прогрев камеры, brim, клей для ABS |
| Трещины между слоями | перепад температур, обдув | снизить обдув, закрыть корпус, поднять t° сопла |
| Деталь «пузатая» | перегрев | немного снизить t° сопла, увеличить обдув на свесах |

## Хранение

Сушка: **70–80 °C, 4–6 ч**. Гигроскопичность низкая–средняя.
