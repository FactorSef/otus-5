# PETG (полиэтилентерефталат-гликоль)

Компромисс между PLA и ABS: прочнее и термостойче PLA, проще ABS.
Пищевой в исходном виде (но печатные детали — нет, из-за пор между слоями).

## Свойства

| Параметр | Значение |
|---|---|
| Температура стеклования | ~75–80 °C |
| Усадка | низкая |
| Гигроскопичность | **средняя–высокая** |
| Прочность | высокая ударная вязкость, гибче PLA |
| Химстойкость | хорошая (масла, слабые кислоты, вода) |
| УФ-стойкость | средняя |

**Применение:** функциональные детали, крепёж, ёмкости, детали для
улицы (кратковременно), механика с умеренными нагрузками.

## Базовые настройки

| Параметр | Значение |
|---|---|
| Сопло | 230–255 °C |
| Стол | 70–85 °C |
| Обдув | 30–60 % (мосты/свесы — до 100 %) |
| Ретракт (директ) | 0,8–1,5 мм |
| Объёмный поток | 10–18 мм³/с (HF-версии — до 25) |
| Z-hop | рекомендуется, PETG «цепляет» сопло |

## Адгезия — главное предупреждение

PETG **слишком хорошо** прилипает к гладкому PEI и стеклу — может вырвать
кусок покрытия. Правила:

- Используйте **текстурированный PEI**.
- На гладкой пластине — тонкий слой клей-карандаша как **разделитель**.
- Не печатайте PETG на холодной пластине (Cool Plate) без клея.

## Разновидности

| Тип | Особенности |
|---|---|
| **PETG HF / High-Speed** | Для высоких скоростей; профиль Bambu PETG HF. |
| **PETG-CF / GF** | Жёстче, стабильнее по размерам, матовый. **Закалённое сопло.** |
| **PCTG** | Более ударопрочный и прозрачный вариант, печать как PETG +5 °C. |
| **rPETG** | Переработанный; бывает непостоянный диаметр — калибровать поток. |

## Типичные проблемы

- **Паутина и «волосы»** — почти всегда влажный филамент. Сушить.
- **Наплывы на сопле, капли на модели** — снизить температуру, включить
  вайпинг, почистить сопло.
- **Пузырьки, треск при печати** — влага.
- **Слабые слои** — поднять температуру, уменьшить обдув.

## Хранение

Сушка: **60–65 °C, 6–8 ч**. Хранить в герметичном боксе с силикагелем.
