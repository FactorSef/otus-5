# TPU (термопластичный полиуретан)

Гибкий, резиноподобный материал. Жёсткость задаётся твёрдостью по Шору:
чем меньше число, тем мягче.

## Свойства

| Параметр | Значение |
|---|---|
| Твёрдость | 98A (полужёсткий) — 95A (стандарт) — 85A и ниже (мягкий) |
| Усадка | низкая |
| Гигроскопичность | **высокая** |
| Износостойкость | отличная |
| Ударная вязкость | отличная |

**Применение:** чехлы, амортизаторы, прокладки, ножки, шины, ремешки,
мягкие вставки в жёсткие детали (мультиматериал).

## Базовые настройки

| Параметр | Значение |
|---|---|
| Сопло | 215–240 °C |
| Стол | 35–60 °C |
| Скорость | 20–60 мм/с (95A), 15–30 мм/с (85A) |
| Объёмный поток | 3–6 мм³/с — **главный ограничитель** |
| Обдув | 50–100 % |
| Ретракт | 0–1 мм, медленный |
| Ironing / Z-hop | Z-hop лучше выключить — тянет нити |

## Советы

- **Сушите всегда**, даже новую катушку: влажный TPU даёт пузыри и паутину.
- Путь филамента должен быть максимально прямым и коротким, без лишнего трения.
  Катушка должна разматываться легко.
- Мягкие TPU (≤85A) склонны скручиваться в экструдере — снижайте скорость,
  проверяйте натяжение прижима.
- Адгезия к PEI очень сильная: дайте столу остыть, при необходимости —
  клей-карандаш как разделитель.
- Заполнение 10–20 % гироид даёт мягкую «губку», 100 % — плотную резину.

## Типичные проблемы

| Дефект | Решение |
|---|---|
| Пропуски экструзии, «щелчки» | снизить скорость/поток, проверить намотку |
| Паутина | сушка, −5 °C, меньше перемещений («Avoid crossing walls») |
| Филамент намотался на шестерню | снизить ретракт до 0, медленнее |

## Хранение

Сушка: **50–60 °C, 6–8 ч**. Хранить герметично.
