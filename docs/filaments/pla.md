# PLA (полилактид)

Самый простой и распространённый материал. Биоразлагаемый (в промышленном
компосте), почти без запаха, минимальная усадка.

## Свойства

| Параметр | Значение |
|---|---|
| Температура стеклования | ~55–60 °C |
| Усадка | очень низкая |
| Гигроскопичность | низкая–средняя |
| Прочность / жёсткость | высокая жёсткость, хрупкий на излом |
| УФ-стойкость | слабая |
| Запах / испарения | минимальные |

**Применение:** прототипы, макеты, фигурки, корпуса для бытовой электроники
(не нагревающейся), декор.
**Не подходит:** детали в машине летом, вблизи нагревателей, под нагрузкой
длительное время (ползучесть), на улице.

## Базовые настройки

| Параметр | Значение |
|---|---|
| Сопло | 200–220 °C (High-Speed PLA: 220–230 °C) |
| Стол | 55–65 °C |
| Обдув | 100 % (кроме первых 1–3 слоёв) |
| Ретракт (директ) | 0,5–1 мм |
| Объёмный поток | 15–22 мм³/с (обычный), до 30+ (High-Speed PLA) |

## Настройки по принтерам

| | Kobra X | P1S | K2 |

## Разновидности

| Тип | Особенности |
|---|---|
| **PLA+ / Tough PLA** | Модифицирован для меньшей хрупкости. +5–10 °C к температуре сопла. |
| **High-Speed PLA** (Hyper, HF) | Пониженная вязкость; нужен для скоростей 250+ мм/с. |
| **Silk PLA** | Блестящий; печатать медленнее (50–150 мм/с) и горячее — для блеска. Слабее межслойно. |
| **Matte PLA** | Матовый, скрывает слои. Чуть более хрупкий, наполнитель может слегка абразивить. |
| **PLA-CF** | С углеволокном. **Абразивный — только закалённое сопло** (P1S — заменить!). Сопло 0,6 мм предпочтительнее. |
| **Wood / Marble / Glow** | С наполнителем. Glow — сильно абразивный. Wood — сопло ≥0,6 мм, иначе засоры. |

## Типичные проблемы

- **Засор в закрытом принтере** — heat creep из-за горячей камеры. Открыть крышку.
- **Нити (stringing)** — снизить температуру на 5–10 °C, просушить катушку.
- **Провисание мостов** — проверить обдув, снизить скорость мостов.
- **Слоновья нога** — снизить температуру стола на 5 °C, включить компенсацию первого слоя.

## Хранение

Сушка при необходимости: **45–55 °C, 4–6 ч**. Подробнее —
[guides/drying-storage.md](../guides/drying-storage.md).
