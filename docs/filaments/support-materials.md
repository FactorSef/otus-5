# Материалы для поддержек

Мультиматериальные системы (ACE Gen2, AMS, CFS) позволяют печатать
поддержки другим материалом — растворимым или легко отделяемым.

## Обзор

| Материал | Основной материал | Удаление | Сложность |
|---|---|---|---|
| **PVA** | PLA, PETG | растворяется в воде | высокая (гигроскопичен, хрупок) |
| **BVOH** | PLA, PETG, ABS, PA | растворяется в воде быстрее PVA | средняя |
| **HIPS** | ABS | растворяется в лимонене / отламывается | средняя, нужен корпус |
| **Support for PLA** (break-away) | PLA | отламывается | низкая |
| **PETG как интерфейс для PLA** | PLA | отламывается (не спекается с PLA) | низкая |
| **PLA как интерфейс для PETG** | PETG | отламывается | низкая |

## Экономичная стратегия: только интерфейс

Растворимые материалы дороги. Печатайте **основу поддержки** основным
материалом, а **интерфейсные слои** (2–3 слоя, контактирующие с моделью) —
материалом поддержки. В слайсерах: *Support → Support/raft interface → filament*.

Это же снижает число смен филамента и отходы.

## PVA

| Параметр | Значение |
|---|---|
| Сопло | 190–220 °C |
| Стол | 45–60 °C |
| Скорость | 50–100 мм/с |
| Сушка | **45–55 °C, 8–12 ч**, хранить в сухом боксе |

- В AMS / CFS / ACE работает **только абсолютно сухой** PVA: влажный
  становится мягким и липким, пересушенный — ломается в трубках.
- Растворение: тёплая вода (40–50 °C), смена воды, перемешивание — от
  нескольких часов до суток.

## HIPS

- Печатается как ABS: 230–250 °C, стол 100 °C, закрытый корпус.
- Подходит для **P1S и K2**; на Kobra X без корпуса — ❌.
- Растворяется в D-лимонене, но обычно его просто отламывают.

## Настройки по принтерам

| | Kobra X | P1S | K2 |
|---|---|---|---|
| PVA | ⚠️ сухой, через ACE | ⚠️ сухой, через AMS | ⚠️ сухой, через CFS |
| BVOH | ⚠️ | ⚠️ | ⚠️ |
| HIPS | ❌ | ✅ | ✅ |
| Support for PLA / PETG-интерфейс | ✅ | ✅ | ✅ |

## Советы

- Z-зазор поддержки при растворимом интерфейсе — **0 мм**: поверхность
  получается почти как у верхней грани.
- При break-away интерфейсе оставьте зазор 0,1–0,2 мм.
- Удаляйте поддержки до того, как деталь наберёт влагу (PVA прилипает намертво).
