# Типовые дефекты и их причины

## Быстрая диагностика

| Дефект | Наиболее вероятные причины | Что сделать |
|---|---|---|
| Паутина (stringing) | влажный филамент, высокая t°, слабый ретракт | сушка → −5 °C → ретракт +0,2 мм |
| Недоэкструзия, пропуски | скорость выше объёмного потока, засор, низкая t° | снизить скорость / поднять t°, проверить сопло |
| Засор в закрытом принтере на PLA | heat creep (горячая камера) | открыть крышку, проверить вентилятор хотэнда |
| Коробление углов | усадка, сквозняк, холодный стол | корпус, brim, t° стола +5 °C, прогрев камеры |
| Трещины между слоями | холодная камера, сильный обдув | меньше обдув, закрыть корпус, t° сопла +5–10 °C |
| Слоновья нога | горячий стол, сопло близко к столу | t° стола −5 °C, Z-offset, компенсация первого слоя |
| Пузыри, треск из сопла | влага | сушка |
| Волны / ghosting | резонансы, ослабленные ремни | input shaping (калибровка), натяжение ремней |
| Сдвиг слоёв | столкновение сопла, ремни, перегрев драйверов | включить Z-hop, проверить ремни |
| Плохие мосты и свесы | слабый обдув, перегрев | обдув 100 %, скорость мостов ниже |
| Неровный первый слой | калибровка, грязная пластина | пересчитать сетку стола, помыть пластину |

## По принтерам

### Anycubic Kobra X
- **ABS/ASA трескается** → нет корпуса, это ожидаемо. См. [abs-asa.md](../filaments/abs-asa.md#kobra-x--как-выжать-максимум-без-корпуса).
- **Ошибки подачи ACE Gen2** → проверьте, что катушка не перекручена и
  кончик филамента обрезан под углом; для TPU — только 95A и жёстче.
- **Смещение первого слоя после смены сопла** → повторить LeviQ 3.0.

### Bambu Lab P1S
- **Засоры на PLA** → снять/приоткрыть верх, особенно летом.
- **AMS не подаёт / ошибка «filament stuck»** → картонная катушка
  проскальзывает (используйте переходные кольца), влажный хрупкий
  филамент, перекрут на катушке.
- **Быстрый износ сопла** → печатали CF/GF/glow на штатной нержавейке. Замените
  хотэнд на закалённый.
- **TPU не идёт** → TPU нельзя через AMS, только внешний держатель.

### Creality K2
- **Засоры на PLA** → приоткрыть верхнюю крышку.
- **CFS: ошибки подачи** → аналогично AMS — перекруты, картон, хрупкий
  филамент; TPU — только с внешнего держателя.
- **PC/PA расслаивается** → у базового K2 нет активного нагрева камеры;
  дольше прогревайте, уменьшайте размер детали или используйте PC-ABS.

## Порядок калибровки новой катушки

1. Сушка (если материал гигроскопичен или катушка уже открыта давно).
2. Температурная башня (temp tower) — выбрать t° по качеству мостов и слоёв.
3. Калибровка потока (flow rate).
4. Калибровка Pressure Advance / Flow Dynamics.
5. Максимальный объёмный поток (max volumetric speed) — особенно для
   High-Speed материалов и TPU.
6. Ретракт — при наличии паутины после всех шагов выше.

Все три слайсера (Bambu Studio, Creality Print, Anycubic Slicer Next)
и OrcaSlicer содержат встроенные калибровочные тесты.
