# Печатные пластины и адгезия

## Типы пластин

| Пластина | Подходит для | Особенности |
|---|---|---|
| **Текстурированный PEI** | PLA, PETG, ABS, ASA, TPU, PA-CF, PC | универсальна, деталь отходит сама после остывания, фактурный низ |
| **Гладкий PEI** | PLA, ABS, ASA | зеркальный низ; PETG и TPU — **только с клеем** (риск повредить покрытие) |
| **Cool Plate / Supertack** | PLA, TPU | для низких температур стола (35–45 °C) |
| **Engineering / High Temp Plate** | PC, PA, ABS | с клеем-карандашом |

Комплектация из коробки:
- **Kobra X** — пружинная сталь с PEI;
- **P1S** — Textured PEI;
- **K2** — пружинная пластина с PEI-покрытием (уточняйте тип в комплекте).

## Клеи и составы

| Средство | Когда использовать |
|---|---|
| Клей-карандаш (PVA) | разделитель для PETG/TPU, улучшение адгезии PA, PC |
| Специализированные клеи (Magigoo и аналоги) | PC, PA, PP — по типу материала |
| Лак для волос | устаревший вариант, загрязняет механику |
| ABS-суспензия (ABS в ацетоне) | ABS на стекле; на PEI обычно не нужна |

## Уход за пластиной

- Обезжиривайте **тёплой водой с моющим средством** (лучший способ для PEI)
  или изопропиловым спиртом 90 %+.
- Не трогайте рабочую поверхность пальцами — жир кожи главный враг адгезии.
- Ацетон допустим для очистки текстурированного PEI редко; гладкий PEI от
  ацетона может мутнеть.

## Чек-лист при плохой адгезии

1. Пластина чистая и обезжиренная?
2. Правильная температура стола для материала?
3. Калибровка Z-offset / первого слоя проведена после смены пластины или сопла?
4. Первый слой: скорость 30–50 мм/с, ширина линии 110–120 %?
5. Обдув на первых слоях выключен или снижен?
6. Для материалов с усадкой: brim, прогрев камеры, нет сквозняков?
7. Филамент сухой?
